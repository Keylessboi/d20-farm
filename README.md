# D20 Farm

An idle D20 dice game built with Rojo.

## Getting Started

1. Install [Rojo](https://rojo.space)
2. Run `rojo serve`
3. Connect Roblox Studio to `localhost:34875`

## Development

- `scripts/lint.sh` — Run linters
- Tests in `tests/` directory

## CI

GitHub Actions runs on every push:
- selene (linting)
- luau-analyze (type checking)
- unit tests
